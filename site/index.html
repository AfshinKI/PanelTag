One small install.

Choose the package for your Ubuntu desktop. Each build uses the appropriate GNOME extension format.

Download .deb ↓

Then run this command in your download folder:

sudo apt install ./paneltag_0.2.1_ubuntu24.04_all.deb

Log out and back in after the first installation. PanelTag enables itself automatically. If you need to enable it manually:

gnome-extensions enable paneltag@afshinki.github.io

Once enabled, your badge returns at every login. Right-click it for settings. Your choices are saved locally.

Compatibility preview · Packages target Ubuntu 20.04, 22.04, and 24.04 with their default GNOME desktops. Package checks pass; live desktop testing is still pending. KDE, Cinnamon, and other desktops are not supported.
