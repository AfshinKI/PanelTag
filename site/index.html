Get PanelTag

Ubuntu 24.04 · GNOME Shell 46

Go to downloads ↗

Download the .deb from GitHub Releases, then run this command in your download folder:

sudo apt install ./paneltag_0.1.1_all.deb

Log out and back in after the first installation, then enable PanelTag:

gnome-extensions enable paneltag@afshinki.github.io

Once enabled, your badge returns at every login. Right-click it for settings. Your choices are saved locally.

Early prerelease · Designed for GNOME 46 on Ubuntu 24.04. Desktop-session validation is still pending. Other Linux desktops are not supported yet.

A few quick answers

Does it start automatically?

Yes, once enabled in GNOME. It starts when you log into your desktop after boot.

Does this demo change my computer?

No. The website is an interactive preview. Install the extension to add the real badge.

Which desktops are supported?

This first prerelease targets GNOME Shell 46 on Ubuntu 24.04. KDE, Cinnamon, and other desktops are not supported.

How do I open the settings?

Right-click the badge. Left-click and keyboard activation work too.
