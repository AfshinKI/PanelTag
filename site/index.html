v0.2.7 compatibility preview · Live desktop testing is still pending.

Not sure which version, or need help?

One installer selects the right extension code for GNOME 3.36–51. Ubuntu 20.04, 22.04, 24.04, 26.04 and 26.10 are package targets; live testing on every release is still pending. Other desktops are not supported.

If GNOME extensions are globally disabled, enable them first. If the badge doesn’t appear after logging back in, run gnome-extensions enable paneltag@afshinki.github.io.
